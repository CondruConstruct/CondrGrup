Condr Grup С.Р.Л. использует только те данные, которые необходимы для ответа на запросы, полученные через сайт.

Собранные данные

Формы могут собирать имя, контактные данные, город, тип работы и информацию, добровольно введенную пользователем.

Цель обработки

Данные используются для ответа на запросы, обсуждения проектов, проверки отзывов и только с согласия публикации отзыва.

Подача форм

Сайт размещается через GitHub Pages, а формы используют внешний сервис FormSubmit для отправки сообщения на адрес Condr Grup. Мы не запрашиваем пароли, банковские реквизиты или другую конфиденциальную информацию через форму.

Хранение и удаление

Мы храним сообщения столько времени, сколько необходимо для анализа запроса и продолжения сотрудничества. Вы можете запросить доступ, исправление или удаление данных, отправленных по электронной почте.

Отзывы

Отзывы не публикуются автоматически. Condr Grup проверяет их и запрашивает согласие на публикацию. Пользователь может попросить отображать полное имя, имя, инициалы или не публиковать.
