# Verified project register

The public portfolio may grow to 100+ projects, but only real work should be published. Add one JSON record per project and keep supporting contracts/permissions outside the public repository.

Publication gate:

1. The scope, year, quantity and public location are confirmed.
2. The client name may be published, or the project is anonymized.
3. Every image is classified as `owned-jobsite`, `licensed-identification`, or `illustrative`.
4. Generated and stock images are never presented as completed Condr Grup work.
5. A Romanian page is created; the locale and SEO tools automatically discover and build all language versions.

Use `_template.json` for each new project. Never store contracts, personal data, exact private-home addresses or signatures here.
